# BursaryBuddy MVP

## Goal
Build a polished, mobile-first, investor-ready BursaryBuddy prototype that demonstrates the complete journey from onboarding through discovery, application preparation, deadlines, and tracking.

## Experience
- Create a welcoming first-run flow with a compact profile setup and a clear path to explore demo opportunities.
- Build a responsive app shell: mobile bottom navigation and an expanded desktop sidebar.
- Add dedicated views for Home, Discover, Applications, Saved, Profile, Deadlines, Notifications, Application Help, and bursary details.
- Use deep blue, warm gold, bright neutral surfaces, accessible status colours, rounded cards, clear typography, and restrained motion.
- Include a compact education-and-growth logo that remains readable at mobile sizes.

## Functional prototype
- Use persistent local demo state for profile, onboarding, saved opportunities, application statuses, document checklists, reminders, and notifications.
- Populate 12 clearly labelled fictional opportunities across education fields and funding types.
- Implement search, category browsing, multi-filter discovery, save/unsave, match explanations, application start/status updates, checklist progress, reminder toggles, profile editing, and notification read states.
- Add success feedback, validation, confirmations, and useful empty states; no inactive buttons.

## Structure
- Use reusable layout, navigation, opportunity, status, progress, filter, and article components.
- Keep structured TypeScript models and demo data separate from presentation code.
- Give every content page unique search/social metadata.

## Validation
- Check the complete investor journey in the running app.
- Verify mobile and desktop layouts, navigation, filters, saves, applications, documents, reminders, profile editing, and accessibility basics.
- Resolve build, runtime, console, and overflow issues before completion.
